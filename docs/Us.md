1. User 
Epic: Landing & Platform Discovery
USER-01: As a User, I want to view the homepage with an introduction to the platform's features (mock tests, AI grading, practice materials), so that I can understand what the platform offers before deciding to register.
USER-02: As a User, I want to browse the list of available IELTS mock tests (titles, skill type, difficulty) without logging in, so that I can evaluate the quality and quantity of practice materials.
Epic: Account Registration & Authentication
USER-03: As a User, I want to register a new account using my Email and Password, so that I can become a Student and access all learning features.
USER-04: As a User, I want to receive an email verification link after registration, so that my account is secured and validated.
USER-05: As a User, I want to log into the system with my registered Email and Password, so that I can access my personalized learning dashboard.
USER-06: As a User, I want to use the "Forgot Password" feature to reset my password via email, so that I can regain access to my account.
Epic: General Information & Support
USER-07: As a User, I want to view a FAQ / About Us page, so that I can learn about the platform's purpose and how the AI evaluation works.
USER-08: As a User, I want to contact the platform via a contact form, so that I can ask questions or report issues before registering.
Epic: Profile Management
USER-09: As a User, I want to view and update my profile information (Name, Avatar, Target Band Score), so that my account is personalized.

2. STUDENT (Học viên)
Epic: Objective Testing (Reading & Listening)
STU-02: As a Student, I want to view and filter a list of available IELTS mock tests, so that I can select a test that matches my current level.
STU-03: As a Student, I want to select between a timed simulation or an untimed practice mode, and have the system automatically submit my answers when the timer reaches zero, so that the test strictly simulates real exam conditions. 
STU-04: As a Student, I want to submit my multiple-choice answers and receive an immediate Band Score, so that I can quickly evaluate my proficiency.
STU-05: As a Student, I want to review my test results with correct/incorrect answers and read the explanations provided by the Tutor. 
STU-06: As a Student, I want to click an "Explain with AI" button under a Tutor's explanation, so that I can get a simplified or deeper breakdown from the AI chatbot.
Epic: Subjective Testing (Writing & Speaking)
STU-07: As a Student, I want to type or upload my Writing Task responses, so that I can choose to submit them either to the AI or to a Tutor for evaluation.
STU-08: As a Student, I want to see a Speaking test and use a built-in web recorder to capture my voice, so that I can choose to submit the audio either to the AI or to a Tutor for evaluation.
STU-09: As a Student, I want to view a detailed feedback report (Band Score, error highlights, suggestions) after my Writing or Speaking test has been graded.
Epic: Offline Resources, Support Chatbot & Progress Tracking
STU-10: As a Student, I want to access the Document Library to download official IELTS PDFs and Audio files, so that I can practice independently offline.
STU-11: As a Student, I want to have an AI Chatbot window constantly available in my studyspace, so that I can ask quick academic questions while studying.
STU-12: As a Student, I want to view my dashboard with average score, target and history of test, so that i can track my progress
STU-13: As a Student, I want to see my remaining "AI Grading Quota" and "Tutor Grading Quota" on my dashboard, so that I know how many subjective tests I can submit this month. 
3. TUTOR (Giáo viên / Người quản lý nội dung)
Epic: Grading & Human Feedback
TUT-01: As a Tutor, I want to view a dashboard queue of pending Writing and Speaking submissions of students so that I can manage my grading workload effectively.
TUT-02: As a Tutor, I want to listen to students' recorded speaking tests and input my criteria scores, so that I can provide personalized human evaluation.
TUT-03: As a Tutor, I want to view an AI-generated preliminary grammar and vocabulary check on a student's essay, so that I can grade faster and focus on logic and coherence.
TUT-04: As a Tutor, I want to record and attach short audio feedback directly within the grading interface so that I can explain pronunciation errors or complex nuances clearly.
TUT-05: As a Tutor, I want to add private notes to a student's profile so that I can track their specific weaknesses for future reference.
Epic: Resource & Test Management
TUT-06: As a Tutor, I want to input text explanations and map them to specific questions in the reading/listening tests, so that students understand the answers.
TUT-07: As a Tutor, I want to upload, edit, and delete PDF documents and Audio files in the Library so that students have up-to-date resources to download.
TUT-08: As a Tutor, I want to edit and update the answer key of an already published test without deleting existing user attempt records so that I can fix typos or incorrect answers smoothly. 
Tutor-09: As a Tutor, I want to schedule the publish date and time for new mock tests so that content is released consistently even when I am not online.

Epic: System Dashboard & Monitoring
ADM-01: As an Admin, I want to view a system dashboard with key metrics (Total users, active tests, AI usage) and recent activities, so that I can quickly monitor platform performance. 
Epic: User Management & Permissions
ADM-02: As an Admin, I want to view a list of all users with search and filter capabilities, so that I can easily find specific accounts. 
ADM-03: As an Admin, I want to create, update, and change roles of user accounts, so that I can ensure they have the correct system access. 
ADM-04: As an Admin, I want to activate, deactivate, or delete users, so that I can manage access control and handle policy violations.
Epic: Reports & Analytics
ADM-05: As an Admin, I want to generate and filter usage reports (User, Test, AI usage) by date range, so that I can analyze platform growth and AI costs.
 Epic: Security & Audit Log
ADM-06: As an Admin, I want to view and filter system activity logs for sensitive actions (role changes, content changes), so that I can audit and investigate issues. 
5. AI SYSTEM (System AI - Back-end Service Actor)
Epic: AI Core Evaluation & Contextual Assistance
AI-01: As an AI System, I want to analyze students’ Writing responses and estimate a Band Score based on Task Achievement, Coherence & Cohesion, Lexical Resource, and Grammatical Range & Accuracy, so that students can receive detailed automated IELTS Writing feedback.
AI-02: As an AI System, I want to process students' Speaking voice recordings, convert speech to text, and evaluate Fluency & Coherence, Lexical Resource, Grammatical Range & Accuracy, and Pronunciation, so that I can generate automated IELTS Speaking reports and Band Scores.

AI-03: As an AI System, I want to receive the Tutor's original explanation text and the corresponding test question, so that I can generate a simplified, personalized breakdown when a student clicks "Explain with AI".
AI-04: As an AI System, I want to act as a chatbot assistant within the student's workspace, so that I can answer general study questions in real-time.
